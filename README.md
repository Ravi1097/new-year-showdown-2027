# New Year Showdown 2027

The Indian Edition — a multiplayer party quiz for four teams and eight players.

## Development

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000

## Environment

Create `.env.local` in the project root and add your Supabase project URL and publishable key. Never add a Supabase service-role key to the browser application.
